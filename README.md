## 🎯 Overview

SpendWise is a lightweight yet powerful expense tracking application built with Flask and modern web technologies. It helps you monitor daily spending, analyze patterns, and make informed financial decisions—all through a clean, responsive interface.

## ✨ Features

### Core Functionality
- **📝 Add Expenses** - Quickly log expenses with date, category, description, and amount
- **📊 Daily Dashboard** - View today's total spending, transaction count, and top category at a glance
- **📅 Multi-level Filtering** - Filter expenses by day, month, or year
- **📈 Visual Analytics** - Interactive doughnut charts showing category-wise spending breakdown
- **📋 Transaction History** - Browse previous transactions with detailed summaries

### User Experience
- **🎨 Modern UI** - Beautiful gradient design with smooth animations
- **📱 Fully Responsive** - Works seamlessly on desktop, tablet, and mobile
- **⚡ Real-time Updates** - Instant refresh after adding expenses
- **🎭 Category Badges** - Color-coded categories for quick visual scanning
- **🔔 Smart Defaults** - Auto-populated date fields for faster entry

### Categories Supported
Food • Transport • Shopping • Bills • Entertainment • Health • Other
